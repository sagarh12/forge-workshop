# Davit: Part C (ask an LLM)

| Notebook | Part | What it does |
|---|---|---|
| `davit_llm_prompting.ipynb` | C | Asks Gemini to label emotions with zero-shot, few-shot and balanced few-shot prompts. |

Steps 1 to 7 use saved results. Only **Step 8** calls Gemini live: paste your own free key into the box when it asks.

Results: `outputs/predictions/zero_shot_predictions.csv`, `few_shot_predictions.csv`, `balanced_few_shot_predictions.csv` (first 100 test lines), plus charts in `outputs/figures/`.
